## This project was created for a school assignment in Android development, september 2026
Built in Java and Kotlin

## Description
The task was to create an app with one profile page/activity, one activity for  
step counting (using the accelerometer) and login/authentication.

I implemented Firebase Realtime Database for storing data associated with the user,  
with Firebase Auth for authentication. Data associated with the step counter  
is stored in SharedPreferences.

*APK-file in release*
